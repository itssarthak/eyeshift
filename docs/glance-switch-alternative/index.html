The free Glance Switch alternative

Eyeshift does what Glance Switch does: look at a screen, window or split pane and keyboard focus moves there. It's free, open source, and runs entirely on your Mac.

Get Eyeshift, freeView on GitHub

Why people look for a Glance Switch alternative

Glance Switch is a polished paid app that switches focus to whatever you look at. If you'd rather not pay for a licence, want to read the code that watches your camera, or want to change how it behaves, Eyeshift is an open-source option that covers the same ground on macOS.

Eyeshift vs Glance Switch

  • Price: Eyeshift is free under the MIT licence. Glance Switch is a paid app.
  • Hardware: both work with a regular webcam, no Tobii or dedicated eye tracker needed. Eyeshift can also combine two webcams.
  • What it switches: both handle screens, windows and split panes. Eyeshift supports panes in iTerm2, Terminal, Ghostty, Warp, kitty, WezTerm, VS Code, Cursor, Windsurf, Zed, Sublime Text, Xcode and JetBrains IDEs.
  • Learning: Eyeshift learns from your clicks and typing as you work, and corrects itself when you click away from a wrong switch.
  • Privacy: Eyeshift processes camera frames in memory with Apple's Vision framework and has no network access. You can verify that in the source.
  • Platforms: Glance Switch supports Mac and Windows. Eyeshift is Mac only for now.

Try it in a minute

git clone https://github.com/itssarthak/eyeshift.git
cd eyeshift && ./build.sh
open ~/Applications/Eyeshift.app
